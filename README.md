# Smart Collar Belt for Livestock Tracking and Management

## 📌 Project Overview
An IoT-based solution designed to help farmers monitor livestock in real-time. This project was developed as part of the **Innovation and Design Thinking (IDT)** curriculum at **CMRIT**.

### Key Features:
* **GPS Tracking:** Real-time location using GPS NEO-6M.
* **Solar Powered:** Integrated solar plates for sustainable energy.
* **Safety:** Radium stickers for night visibility and Geo-fencing alerts.

## 🛠️ Hardware Components
* Arduino Uno
* GPS NEO-6M Module
* Adjustable Belt
* Solar Panel Power Supply

## 💡 Design Thinking Process
1. **Empathy:** Conducted interviews with farmers regarding cattle theft and grazing loss.
2. **Define:** Focused on reducing manual labor and improving herd security.
3. **Ideate:** Brainstormed a wearable IoT device with geo-fencing capabilities.
4. **Prototype:** Built a functional GPS-tracking collar.
5. **Test:** Validated in open-sky environments for location accuracy.
